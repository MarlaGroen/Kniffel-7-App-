# Kniffel 7

Mobile, werbefreie Punktekarte für Kniffel 7.

## Spielumfang
- 2 Spieler: Florian und Sarah
- 14 Wertungsfelder
- Festwertungen werden per Tap direkt übernommen
- Variable Wertungen öffnen nur bei Bedarf die Punkteingabe
- Separates Streichen
- Automatischer Spielerwechsel und Rundenzähler
- Bonusberechnung: +35 ab 63, zusätzlicher Top-Bonus +35 ab 84
- Rückgängig und neue Partie
- Lokale Speicherung des Spielstands
- Offline-fähig und als PWA installierbar

## Installation
Über GitHub Pages bereitstellen und anschließend im mobilen Browser „Zum Startbildschirm hinzufügen“ bzw. „App installieren“ wählen.

Alle Spielstände bleiben lokal im Browser des Geräts.
