# Kniffel 7

Mobiler Punkteblock für die Kniffel-Variante mit sieben Würfeln und zwei Spielern.

## Funktionen

- 14 Kategorien inklusive Siebener, Doppel-Tripel und Super-Kniffel
- Automatische Summen sowie Bonus ab 63 und Top-Bonus ab 84
- Spielernamen, Zug- und Rundenanzeige
- Rückgängig, Streichen, Revanche und lokaler Spielstand
- Offline-Modus und installierbare PWA
- Für Smartphone und Desktop optimiert

## Lokal starten

```bash
python3 -m http.server 8080
```

Die App ist für GitHub Pages vorbereitet.
